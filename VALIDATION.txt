MotionWall 1.1.0 — video screen saver update, 2026-10-22

Implemented:
- Native Objective-C ScreenSaverView bundle, separate AVQueuePlayer and
  AVPlayerLooper per view, muted video, fill/fit setting, low-power pause,
  error placeholder, explicit release on stop/deallocation/window detach.
  Observed system stop/unlock notifications provide best-effort additional
  teardown for legacy hosts that omit stopAnimation; no host is terminated.
- Video and settings are copied inside the installed .saver bundle.
  The host does not need access to MotionWall app data or the original file.
- Background installation stages, signs and verifies the complete bundle
  before replacing an existing owned MotionWall.saver. Failure attempts
  rollback; a failed rollback preserves the old bundle for recovery.
- Main application offers install/update, system settings links and launch
  of the screen saver currently selected by macOS. On macOS 26+ the
  settings link opens Wallpaper because the old saver pane was removed.
- User enables immediate password requirement in macOS. The app neither
  reads nor changes password settings and does not impersonate a lock screen.
- Optional 30-minute display/idle-sleep inhibition uses Apple's caffeinate
  with a timeout and parent-pid watcher; stops on app exit or system sleep.
  No permanent power settings are changed. Explicit sleep is not prevented.
- Installer builds and signs the .saver, then runs a native bundle load and
  start/animate/stop smoke check on the user's Mac before replacing the app.
