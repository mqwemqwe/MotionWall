Manual source review and corrections:
- Separate AVQueuePlayer/AVPlayerLooper per monitor, avoiding reuse of
  one AVPlayer across multiple player layers.
- Desktop windows ignore mouse events and cannot become key/main.
- Window level is directly below desktop icon level, above background.
- Lifetime of loops and windows is retained after settings panel closes.
- Playback failures from retired windows cannot remove newer sessions.
- Item and looper failures are surfaced, returning to the system wallpaper.
- Import uses a temporary output; current wallpaper is preserved on failure
  or cancellation. Input files are never overwritten.
- Cancellation terminates only the associated converter process.
- Preferences are written atomically before applying user state changes.
- Installer checks its prerequisites before changing the installed app,
  stages a new bundle, and preserves the previous version on replacement.
- No video uploads, screen recording, Accessibility control or telemetry.
